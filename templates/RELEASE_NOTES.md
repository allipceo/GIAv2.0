# 릴리스 노트 템플릿

## STAGE 4-4 운영 고정화 · 문서화 마감

**릴리스 버전**: v4.4.0  
**릴리스 날짜**: 2025-10-03  
**릴리스 유형**: 운영 고정화  

### 개요

ZOBIS 시스템의 운영 고정화 및 문서화 마감을 위한 STAGE 4-4 릴리스입니다. KPI 자동 수집, 링크 검증 배치화, 운영 알림 시스템을 구축하고, 모든 운영 기준을 문서화했습니다.

### 주요 변경사항

#### 1. KPI 자동 수집 배치화
- **Linux cron 기반**: 일 1회 자동 수집 (매일 02:00)
- **수집 지표**: 성공률, P95 지연시간, 중복 스킵률, 실패 원인 분포
- **rolling 윈도우**: 7일 rolling 지표 수집
- **임계값 설정**: P95 경고 > 6.0s, 위험 > 8.0s
- **실패 처리**: 재시도 1회 + 로그 태깅

#### 2. 링크 검증 배치화
- **대상 링크**: C2N2/C2N3 최근 24시간 링크 자동 탐지
- **검증 기준**: HTTP 200, 응답 ≤1.5s, SSL 유효성, Notion URL 형식
- **리다이렉션**: 3xx 1회 자동 추적 허용
- **실패 처리**: 재시도 1회 + 표준 err_code 기록

#### 3. 운영 알림 시스템
- **알림 채널**: Slack (1차) → 이메일 (2차) → Notion (3차)
- **알림 조건**: P95 위험 30분 지속, 링크 실패 3건 이상
- **메시지 템플릿**: 경고/해제 알림 표준화
- **에스컬레이션**: 3단계 우선순위 알림

#### 4. ZNNN_ 번호체계 운영 기준
- **패턴**: ^Z\d{3}_ (Z001_ ~ Z999_)
- **동작**: 원자적 예약 → 충돌 스킵 → 이력 기록
- **회귀 테스트**: 멀티스레드 동시성 + 5~10ms 지연
- **성공 기준**: 90% 이상 성공률
