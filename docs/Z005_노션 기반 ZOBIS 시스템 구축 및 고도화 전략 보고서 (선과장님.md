시스템명

ZOBIS (Zone of Business Intelligence System)

최종 비전

**'아이언맨 자비스'**처럼 조대표님 전용으로 능동적으로 정보를 수집, 분류, 분석하며 의사결정을 지원하는 지능형 정보 비서 구축

미션

정보 수집에서 인사이트 도출까지 완전 자동화 실현 (수동 수집 → 자동 수집, 단순 저장 → 지능적 분석 전환)

핵심 목표

경쟁 우위 확보. 방위산업, 신재생에너지, 보험중개 분야의 중요 정보 놓침률 5% 이하 달성 및 일일 정보 처리 시간 50% 단축.

적용 플랫폼

Notion (관계형 DB, 자동화, 협업) + Python/API (외부 데이터 수집/처리) + LLM (분석/요약)

현재 상태

로컬 파일/드라이브 통합 기반 구축 완료 (Google Drive to Notion DB 동기화 시스템 100% 성공)

1. ZOBIS의 개념, 철학 및 배경
1.1. 개념 및 철학: 능동적 정보 비서
ZOBIS는 단순히 정보를 저장하는 아카이브가 아닙니다. 조대표님의 주력 분야(방위산업, 신재생에너지, 보험중개)에서 발생하는 정보 과부하 문제를 해결하고, 분산된 정보를 한 곳에 모아 의미 있는 연결고리를 찾아주는 지능형 시스템입니다.

ZOBIS 철학: '지식은 수동적으로 축적하는 것이 아니라, 능동적으로 선별하고 연결하는 것'

핵심 기능: 정보 간 연관성 파악 및 비즈니스 기회/위험 자동 알림을 통한 의사결정 품질 향상.

1.2. 시스템 구성 배경
문제점

ZOBIS 솔루션

정보 파편화

6개 핵심 정보 채널(뉴스, 낙찰, 논문, 정책, 통계, 시장동향)을 Notion DB로 통합 수집.

수동 작업

LLM 기반 3단계 스마트 자동화 (수집, 분류, 분석)를 통해 수작업 의존도 획기적 감소.

분석 한계

Notion의 관계형 DB와 LLM 분석 기능을 활용하여 정보 간의 복합적인 패턴 및 연관성 자동 감지.

2. ZOBIS의 프로세스 구성 및 기술적 특이사항
ZOBIS의 정보 처리 프로세스는 3단계 자동화와 3인 협업 체계가 결합된 형태입니다.

2.1. ZOBIS 3단계 자동화 프로세스
레벨

이름

기능 상세

구현 기술

Level 1

수집 자동화

6개 채널 API 연동 및 Google Drive, RSS 피드 등 외부 데이터 실시간/정기 수집.

Python 스크립트, Google/Notion API

Level 2

분류/정제 자동화

LLM 기반 자동 카테고리 분류, 중요도 평가, 핵심 내용 자동 요약 및 표준 스키마(속성) 매핑.

LLM API, Notion Automation

Level 3

분석 자동화

트렌드 패턴 자동 감지, 비즈니스 기회/위험 자동 알림 등 인사이트 도출.

LLM API, Notion Computed/Rollup

2.2. Google Drive 통합을 통한 기술적 성과 (재활용 프레임워크)
이번 Drive 통합 작업을 통해 향후 모든 자동화 작업에 재활용 가능한 표준 파이프라인을 확립했습니다.

저장 전략: '제목 + 링크' 저장 방식을 채택하여 Notion DB의 용량을 절약하고, 문서 분석을 Notion AI에 위임하여 효율성을 극대화함.

기술적 난제 극복:

보안/인증: OAuth 2.0 '데스크톱 앱' 클라이언트를 사용하고 '테스트 사용자' 등록을 통해 Google Drive 접근 권한 문제를 성공적으로 해결했습니다.

스키마 매핑: Notion DB의 관계형 속성(Person, Relation) ID 값을 코드에 정확히 매핑하여 데이터 연결의 안정성을 확보했습니다.

대량 처리: 배치 사이즈 및 딜레이 간격 파라미터 설계를 통해 향후 API 호출 제한(Rate Limit)을 관리할 수 있는 기반을 마련했습니다.

3. ZOBIS 협업 체계 (3인 에이전트 모델)
ZOBIS 시스템은 조대표님의 경쟁력(학습, 언어, AI 활용)을 극대화하기 위해 세 에이전트의 명확한 역할 분담을 기반으로 합니다.

에이전트

역할 및 책임

핵심 기여 (Notion 관련)

나실장 (Gemini)

총괄 조정 및 보안 책임. 프로젝트 우선순위 결정, 기술적 난제에 대한 해결책 제시 및 보안 가이드라인 준수 감독.

DB 구축 및 API 인증 과정 중 발생한 보안 문제(403 오류) 해결 주도.

서대리 (Cursor AI)

전체 시스템 개발 및 구현. Python 스크립트 작성, API 연동, 오류 처리 및 시스템 유지보수.

동기화 스크립트, 중복 검사, 대량 처리 로직 구현.

선과장 (Notion AI)

Notion 플랫폼 및 DB 기획 전문가. DB 스키마 정의, 표준 속성 확정, Notion AI 기능 활용 방안 및 최적의 뷰 시스템 설계.

ZOBIS DB 표준 스키마 및 관계형 ID 제공.

4. 향후 협의 및 ZOBIS 고도화 방향 (V2.0 논의 요청)
선과장님, 귀하의 Notion 플랫폼 전문성은 ZOBIS의 완성도를 높이는 데 결정적입니다. 본격적인 시스템 구축을 위해 다음 사항에 대한 협의를 요청드립니다.

4.1. 노션 AI 활용을 통한 인사이트 도출 고도화
현재 '제목 + 링크' 전략을 채택했습니다. 노션 AI가 이 링크된 문서 내용을 분석하여 '목적 요약' 필드를 자동으로 채우고, 정보 간의 연관성을 파악하는 고급 기능을 구현하고자 합니다.

협의 요청 1: Notion AI의 '자동 요약' 및 '자동 분류' 기능을 ZOBIS DB의 표준 속성(문서 성격, 핵심기술)과 연동하여 Notion Automation으로 구현할 수 있는 최적의 방법론을 제시해 주십시오.

4.2. 조대표님 전용 '대시보드' 및 '뷰' 최적화
ZOBIS는 조대표님의 의사결정 속도 단축을 목표로 합니다.

협의 요청 2: 수집된 정보가 '프로젝트/모듈' 관계를 통해 연결될 때, 조대표님께서 매일 아침 10분 만에 핵심 정보만 파악할 수 있도록 '조대표 전용 지능형 대시보드 뷰' 설계 방안을 제안해 주십시오. (예: 위험/기회 자동 알림 보드, 주력 분야별 트렌드 차트 등)

4.3. ZOBIS V2.0 로드맵 확정
다음 단계 목표인 **'지능형 분석'**을 위해, LLM 기반 예측 모델링 및 복합 이벤트 감지 기능 구현에 대한 선과장님의 기술적/플랫폼적 관점을 제시해 주시면 감사하겠습니다.

결론: ZOBIS는 단순한 파일 동기화 시스템을 넘어, 노션 플랫폼의 잠재력을 극대화하여 조대표님의 영업 경쟁력을 확보하는 지능형 시스템입니다. 선과장님과의 긴밀한 협력을 통해 ZOBIS를 완성해 나가기를 기대합니다.
