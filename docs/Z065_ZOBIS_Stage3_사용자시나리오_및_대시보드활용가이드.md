# Z065: ZOBIS Stage 3 사용자 시나리오 및 대시보드 활용 가이드

## 1. ZOBIS Stage 3가 조대표님 업무에 도움을 주는 방식

### 1.1 핵심 가치 제안
**"AI가 24시간 자동으로 시장 정보를 수집하고 분석하여 비즈니스 인사이트를 제공하는 지능형 비서"**

### 1.2 구체적 업무 도움 방식

#### A) **자동 정보 수집 및 분석**
- **기존**: 조대표님이 직접 뉴스, 보고서, 정부 발표 등을 일일이 검색하고 분석
- **ZOBIS**: 키워드만 입력하면 AI가 자동으로 관련 정보를 수집하고 구조화된 분석 제공
- **시간 절약**: 하루 2-3시간 → 10분으로 단축

#### B) **전략적 의사결정 지원**
- **시장 동향 파악**: 특정 산업/기업에 대한 실시간 정보 수집
- **리스크 분석**: 정부 정책, 규제 변화, 경쟁사 동향 자동 모니터링
- **기회 발굴**: 새로운 사업 기회나 파트너십 가능성 조기 발견

#### C) **고객 맞춤형 인사이트**
- **영업 준비**: 특정 기업 대상 영업 전에 해당 기업의 최신 동향, 리스크, 기회 분석
- **제안서 작성**: AI가 수집한 데이터를 바탕으로 맞춤형 보험 솔루션 제안
- **관계자 분석**: 핵심 인물의 최신 동향과 영향력 분석

## 2. ZOBIS 대시보드에서 Stage 3 기능 사용법

### 2.2 Stage 3 기능 사용 시나리오

#### **시나리오 1: 특정 기업 모니터링**
1. **대시보드 접속** → "정보 수집" 탭 클릭
2. **키워드 입력**: "효성중공업 해상풍력" 또는 "두산중공업 신재생에너지"
3. **수집 설정**: 
   - 수집 기간: 최근 1개월
   - 정보 유형: 뉴스, 보고서, 정부 발표
   - 분석 깊이: 심층 분석
4. **실행**: "자동 수집 시작" 버튼 클릭
5. **결과 확인**: 10-15분 후 "분석 결과" 탭에서 구조화된 보고서 확인

#### **시나리오 2: 시장 동향 실시간 모니터링**
1. **대시보드** → "실시간 모니터링" 탭
2. **관심 키워드 등록**: 
   - "해상풍력 정책"
   - "신재생에너지 보험"
   - "정부 에너지 정책"
3. **알림 설정**: 
   - 중요도: 높음/중간/낮음
   - 알림 방식: 이메일/대시보드/모바일
4. **자동 모니터링**: 24시간 자동 수집 및 분석
5. **인사이트 확인**: 매일 오전 9시 요약 보고서 자동 생성

#### **시나리오 3: 영업 준비 및 제안서 작성**
1. **대시보드** → "분석 결과" → "기업 분석" 클릭
2. **대상 기업 선택**: 드롭다운에서 "효성중공업" 선택
3. **분석 범위 설정**:
   - 재무 현황
   - 사업 전략
   - 리스크 프로파일
   - 보험 니즈
4. **AI 분석 실행**: "종합 분석 시작" 버튼
5. **결과 활용**:
   - 영업 전략 수립
   - 맞춤형 제안서 작성
   - 리스크 평가서 생성

## 3. 실제 업무 활용 예시

### 3.1 **영업 준비 시나리오**
**상황**: 효성중공업 대상 영업 미팅 준비
**ZOBIS 활용**:
1. 키워드: "효성중공업 해상풍력 사업 현황"
2. 수집 결과: 최신 사업 동향, 정부 정책, 경쟁사 분석
3. AI 분석: 리스크 프로파일, 보험 니즈, 제안 포인트 도출
4. 영업 활용: 맞춤형 제안서 작성, 리스크 평가서 준비

### 3.2 **시장 동향 파악 시나리오**
**상황**: 신재생에너지 시장의 최신 동향 파악 필요
**ZOBIS 활용**:
1. 키워드: "신재생에너지 정책 변화", "해상풍력 시장 동향"
2. 실시간 모니터링: 정부 발표, 업계 뉴스 자동 수집
3. AI 분석: 정책 변화가 보험 시장에 미치는 영향 분석
4. 전략 수립: 새로운 사업 기회 발굴 및 대응 전략 수립

### 3.3 **리스크 관리 시나리오**
**상황**: 기존 고객사의 리스크 변화 모니터링
**ZOBIS 활용**:
1. 키워드: "두산중공업 사업 리스크", "해상풍력 기술 리스크"
2. 자동 모니터링: 24시간 리스크 신호 감지
3. AI 분석: 리스크 등급 변화, 새로운 리스크 요소 식별
4. 대응: 보험 조건 조정, 추가 보장 제안

## 4. 성과 측정 및 ROI

### 4.1 **정량적 성과**
- **시간 절약**: 정보 수집 시간 90% 단축 (3시간 → 20분)
- **정확도 향상**: AI 분석으로 놓치는 정보 80% 감소
- **영업 효율**: 제안서 작성 시간 70% 단축

### 4.2 **정성적 가치**
- **전략적 우위**: 시장 변화 조기 감지로 선제적 대응
- **고객 만족**: 맞춤형 분석으로 고객 신뢰도 향상
- **의사결정 품질**: 데이터 기반 의사결정으로 리스크 감소

## 5. 다음 단계 발전 방향
