## 🎯 STAGE 5-6 목표

실시간 상태 추적 및 성능 모니터링을 위한 대시보드 구축

### 주요 기능
- **KPI 대시보드**: 48h·7d KPI 실시간 표시

- **성능 메트릭**: 응답시간, 성공률, 트렌드 분석

- **로그 데이터**: 실행 로그 및 메트릭

## 📊 대시보드 구성

### 1. KPI 대시보드
- **48h KPI**: 성공률, P95 지연시간, 총 요청수
- **7d KPI**: 성공률, P95 지연시간, 총 요청수
- **트렌드 분석**: 상승/하락/동일 화살표
- **실시간 업데이트**: 15분 간격 자동 갱신

### 2. 링크 상태 모니터링
- **검증 상태**: 성공/실패/대기 중
- **응답시간**: 평균, P95, 최대 지연시간
- **연속 실패**: L1/L2/L3 경보 상태
- **실시간 업데이트**: 5분 간격 자동 갱신

### 3. 경보 시스템
- **활성 경보**: 현재 발생 중인 경보
- **경보 이력**: 최근 24시간 경보 기록
- **해제 메시지**: 정상 복귀 알림
- **실시간 업데이트**: 즉시 반영

### 4. 성능 메트릭
- **시스템 상태**: CPU, 메모리, 디스크 사용률
- **네트워크**: 대역폭, 연결 수, 응답시간
- **데이터베이스**: Redis 연결, 쿼리 성능
- **실시간 업데이트**: 1분 간격 자동 갱신
