## 🔧 용어 통일

### 기술 용어
- **ZOBIS**: Javis-Oriented Business Intelligence System
- **STAGE 5-1~5-7**: ZOBIS 시스템 구축 단계
- **KPI**: Key Performance Indicator
- **API**: Application Programming Interface
- **CI/CD**: Continuous Integration/Continuous Deployment
- **GCR**: Google Container Registry
- **Redis**: Remote Dictionary Server
- **JSONL**: JSON Lines
- **WebSocket**: 웹소켓 통신
- **Docker**: 컨테이너 플랫폼

### 운영 용어
- **경보**: Alert, 경고, 주의, 위험
- **L1/L2/L3**: 경보 단계 (경고/주의/위험)
- **스킵**: Skip, 충돌 시 실행 건너뛰기
- **충돌**: Conflict, 동시간대 동일 대상 실행
- **고유번호**: Unique ID, ZNNN_ 형식
- **이력**: History, 실행 이력 기록
- **스냅샷**: Snapshot, 특정 시점 데이터 캡처
- **마감**: Closure, 문서·프로젝트 완료

### 파일 용어
- **증빙**: Evidence, 증명 자료
- **보고서**: Report, 진행경과 및 결과보고서
- **스크립트**: Script, 실행 스크립트
- **설정**: Configuration, 설정 파일
- **템플릿**: Template, 템플릿 파일
- **로그**: Log, 실행 로그
- **스냅샷**: Snapshot, 데이터 스냅샷
