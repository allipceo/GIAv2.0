## 📋 **시나리오 1: 일상적인 문서 관리 워크플로우**

### **🎯 시나리오 개요**
조대표님이 Google Drive에 새로운 문서를 업로드하면, ZOBIS 시스템이 자동으로 분석하여 Notion DB에 정리하는 완전 자동화 워크플로우

### **📝 단계별 실행 과정**

#### **1단계: 문서 업로드 (Google Drive)**
```
📍 위치: Google Drive "ZOBIS/INBOX" 폴더
📄 작업: 새로운 문서 업로드
⏰ 시간: 언제든지
```

**실행 방법:**
1. Google Drive에서 `ZOBIS/INBOX` 폴더로 이동
2. 새로운 문서를 드래그 앤 드롭 또는 업로드
3. 문서가 업로드되면 자동으로 ZOBIS 시스템이 감지

#### **2단계: 자동 분석 및 분류 (ZOBIS AI)**
```
🤖 AI 분석: 문서 내용 자동 분석
📊 분류: 문서 유형, 중요도, 태그 자동 지정
📝 요약: 핵심 내용 자동 요약
⏱️ 처리시간: 평균 18.5초
```

**AI가 자동으로 수행하는 작업:**
- **문서 유형 분류**: 개발경과, 매뉴얼, 회의록, 기획문서, 보고서
- **중요도 평가**: High, Medium, Low
- **태그 지정**: ZOBIS, 프로젝트명, 기술스택 등
- **핵심 내용 요약**: 3-5줄 요약문 자동 생성

#### **3단계: Notion DB 자동 업데이트**
```
📊 위치: 📘 ZOBIS 개발문서 DB
🔄 동기화: Google Drive → Notion 자동 동기화
📋 속성: 모든 메타데이터 자동 입력
```

**Notion DB에 자동으로 입력되는 정보:**
- **문서 제목**: Google Drive 파일명
- **Google Drive URL**: 원본 파일 링크
- **문서 유형**: AI가 분류한 유형
- **상태**: 자동 분류 완료
- **작성일**: Google Drive 업로드 날짜
- **작성자**: 조대표님
- **태그**: AI가 지정한 태그들
- **프로젝트/모듈**: ZOBIS 시스템 구축
- **목적 요약**: AI가 생성한 핵심 내용 요약

#### **4단계: 실시간 모니터링 및 확인**
```
📊 대시보드: ZOBIS 모니터링 대시보드
🔔 알림: 처리 완료 시 자동 알림
📈 통계: 처리 현황 및 성능 지표
```

**확인 방법:**
1. **Notion DB 확인**: 📘 ZOBIS 개발문서 DB에서 새로 추가된 문서 확인
2. **상태 확인**: "자동 분류 완료" 상태로 표시
3. **요약 확인**: "목적 요약" 필드에 AI가 생성한 요약문 확인
4. **태그 확인**: 자동 지정된 태그들 확인

### **🎯 시나리오 개요**

```
🔍 진단: 자동 진단 및 원인 분석
```

**장애 감지 방법:**
1. **Slack 알림**: #zobis-critical 채널에서 즉시 알림 수신
2. **대시보드 확인**: 모니터링 대시보드에서 빨간색 경고 확인

#### **2단계: 장애 분류 및 대응**
```
📋 분류: P1(30분) ~ P4(24시간) RTO
🔄 대응: L1(24/7) → L2(업무시간+온콜) → L3(온콜)
⏱️ 복구: 평균 15분 복구 시간
```

**장애 대응 절차:**
1. **P1 Critical**: 시스템 완전 중단 → 즉시 온콜 호출
2. **P2 High**: 주요 기능 장애 → 1시간 내 해결
3. **P3 Medium**: 부분 기능 장애 → 업무 시간 내 처리
4. **P4 Low**: 미미한 성능 저하 → 일반 티켓 처리

#### **3단계: 복구 및 검증**
```
🔧 복구: 자동/수동 복구 절차 실행
✅ 검증: 시스템 정상화 확인
📊 모니터링: 지속적인 상태 모니터링
```

**복구 방법:**
1. **자동 복구**: 시스템이 자동으로 복구 시도
2. **수동 개입**: 필요시 수동으로 복구 절차 실행
3. **검증**: 복구 후 시스템 정상화 확인
4. **모니터링**: 지속적인 상태 모니터링 및 알림
