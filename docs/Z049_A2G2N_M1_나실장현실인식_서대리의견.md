## 🎯 **서대리 추가 진단 및 의견**

### **1. Flask 자동 .env 로드 문제 (예상치 못한 블로커)**

**나실장님 진단**: G2N 웹훅 미가동 (실행 문제)
**서대리 추가 진단**: Flask의 자동 `.env` 로드로 인한 `UnicodeDecodeError`

**상세 분석:**
- **문제**: Flask가 `app.run()` 호출 시 자동으로 `cli.load_dotenv()` 실행
- **영향**: `.env` 파일의 BOM 문제로 인해 서버 시작 불가
- **오류**: `UnicodeDecodeError: 'utf-8' codec can't decode byte 0xff in position 0`

**서대리 의견:**
- **나실장님 진단이 정확**: 서버 프로세스 시작 문제
- **추가 발견**: Flask 자동 `.env` 로드 문제로 인한 시작 실패
- **해결 필요**: Flask 설정에서 자동 `.env` 로드 비활성화 또는 대안 서버 사용

### **2. Notion DB 속성 불일치 문제 (디테일 문제)**

**나실장님 진단**: Notion 속성 400 오류 (디테일 문제)
**서대리 추가 진단**: 최소 세트 속성명 적용 완료, 실제 DB 스키마 확인 필요

**상세 분석:**
- **완료된 작업**: 선과장님 지시사항에 따른 최소 세트 속성명 적용
- **적용된 속성**: 문서 제목, 링크, Google Drive URL, 수집 경로, 작성일, 상태
- **문제**: 실제 Notion DB 스키마와 100% 일치 여부 미확인

**서대리 의견:**
- **나실장님 진단이 정확**: Notion DB 속성 불일치 문제
- **추가 작업**: 실제 Notion DB 화면에서 속성명 1:1 비교 필요
- **해결 필요**: 실제 DB 스키마 확인 후 속성명 정확히 매칭

## 🔧 **서대리 제안 해결 방안**

### **1. G2N 웹훅 서버 시작 문제 해결**

**나실장님 제안**: 서버 프로세스 시작 명령
**서대리 추가 제안**: Flask 자동 .env 로드 문제 해결

**해결 방안:**
1. **Flask 자동 .env 로드 비활성화**
   ```python
   app.config['LOAD_DOTENV'] = False
   ```

2. **대안 서버 사용 (FastAPI)**
   ```python
   from fastapi import FastAPI
   app = FastAPI()
   ```

3. **환경변수 직접 설정**
   ```python
   import os
   os.environ['NOTION_TOKEN'] = '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'
   ```

4. **.env 파일 완전 제거**
   - `.env` 파일을 완전히 제거하고 환경변수 직접 설정
   - BOM 문제 완전 회피

### **2. Notion DB 속성 불일치 문제 해결**

**나실장님 제안**: 실제 Notion DB 화면에서 속성명 1:1 비교
**서대리 추가 제안**: 단계별 속성명 검증

**해결 방안:**
1. **실제 Notion DB 스키마 확인**
   - 프로젝트리소스 DB 열기
   - 속성명 정확히 확인 (띄어쓰기, 대소문자 포함)
