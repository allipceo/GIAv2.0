- **고유번호 정책**: ^Zd{3}_.+$ 패턴, 경합 시 100% 고유번호 부여
- **대시보드 시스템**: Flask + Chart.js 기반 실시간 모니터링
- **경보 시스템**: L1/L2/L3 단계별 경보, 15분 중복 억제

## 🚀 핵심 성과

### 1. 실행 예약·충돌 스킵·이력 기록 (Redis 통합)
- **예약 스키마**: `reservations:{task_id}` Redis Hash 구조
- **충돌 감지**: `running:{target}:{time_bucket}` 키 기반 락 시스템
- **표준 이력**: JSONL 형식, 7일 보관 후 gz 압축
- **고유번호 생성**: `Z{문서번호}_{UTC-YYYYMMDDHHmmss}` 패턴

### 2. 고유번호 정책(경합 방지)
- **패턴 정규식**: ^Zd{3}_.+$ (예: Z083_..., Z072_...)
- **생성 규칙**: base_id + 증분 suffix (-001, -002...)
- **경합 시도**: 100% 고유번호 부여 보장
- **패턴 일치율**: 100% (6건 모두 일치)

### 3. 대시보드·알림 확장
- **대시보드 카드**: 최근 실행, 경합 발생, 스킵·성공 비율, 응답시간
- **업데이트 주기**: 5분 주기 메트릭 수집, 5~10분 화면 갱신
- **경보 단계**: L1(2회) → L2(3회) → L3(5회 또는 10분 내 경합 3회)
- **알림 채널**: Slack 기본, L3 시 이메일 병행

### 4. 운영 가드·성능
- **마스킹 강화**: 토큰, 내부 URL, page_id 일부 마스킹
- **재시도 정책**: 5s → 15s → 45s 백오프 (3회)
- **성능 최적화**: 최근 N건만 스캔, 비동기 버퍼 flush
- **Redis 모니터링**: CPU·메모리·연결 수 메트릭 수집

```python
def detect_conflict(target, time_bucket):
    lock_key = f"running:{target}:{time_bucket}"
    if redis.exists(lock_key):
        return True, "conflict_detected"
    redis.setnx(lock_key, "locked")
    return False, "locked"
```

### 2. 의존성 설치
- **문제**: redis, APScheduler 모듈 미설치
- **해결**: pip install redis APScheduler
- **결과**: 모든 의존성 정상 설치 완료

### 3. 충돌 감지 로직
- **문제**: 동시간대 동일 대상 실행 충돌
- **해결**: `running:{target}:{time_bucket}` 키 기반 락 시스템
- **결과**: 충돌 시 자동 스킵 처리

### 4. 고유번호 생성
- **문제**: 경합 시 고유번호 중복 가능성
- **해결**: 증분 suffix (-001, -002...) 부여
