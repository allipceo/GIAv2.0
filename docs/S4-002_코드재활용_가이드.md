## 🎯 **재활용 전략 개요**

### **문제점**
- 케이스1,2,3마다 동일한 코드를 다시 작성하는 비효율성
- 노션 DB 접근, 페이지 식별, 콘텐츠 업데이트 로직의 중복 개발
- 향후 유사한 작업 시 개발 시간 낭비

### **해결책**
- **모듈화된 워크플로우 시스템** 구축
- **재활용 가능한 컴포넌트** 분리
- **통합 실행 스크립트** 제공

## 🏗️ **재활용 가능한 시스템 구조**

### **1. 핵심 모듈**

```
src/
├── workflows/
│   └── notion_collaboration.py    # 통합 워크플로우 엔진
├── utils/
│   └── notion_api.py              # Notion API 클라이언트
└── config/
    └── workflows/
        └── notion_collaboration.json  # 워크플로우 설정
```

### **2. 실행 스크립트**

```
scripts/
└── run_notion_workflow.py         # 통합 실행 스크립트
```

## 🚀 **재활용 방법**

### **A. 개별 케이스 실행**

```bash
# 케이스1: 통합·권한 핸드셰이크
python scripts/run_notion_workflow.py --case 1

# 케이스2: 페이지 식별
python scripts/run_notion_workflow.py --case 2 --target "Z062"

# 케이스3: 콘텐츠 업데이트
python scripts/run_notion_workflow.py --case 3 --target "Z062"
```

### **B. 전체 워크플로우 실행**

```bash
# 전체 워크플로우 (케이스1+2+3)
python scripts/run_notion_workflow.py --case all --target "Z062"
```

### **C. 배치 처리**

```bash
# 여러 키워드에 대해 배치 처리
python scripts/run_notion_workflow.py --case all --target "Z062" --out logs/result_Z062.json
python scripts/run_notion_workflow.py --case all --target "Z063" --out logs/result_Z063.json
```

```
    ├── result_Z062.json

```

### **결과 분석**

```python
# 결과 파일 분석
import json

with open('logs/result_Z062.json', 'r', encoding='utf-8') as f:
    result = json.load(f)
    
print(f"전체 상태: {result['overall_status']}")
print(f"케이스별 결과:")
for case_name, case_result in result['cases'].items():
    print(f"  {case_name}: {case_result['overall_status']}")
```
