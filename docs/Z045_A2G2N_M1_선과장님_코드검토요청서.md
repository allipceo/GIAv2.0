## 🎯 **핵심 차단 이슈**

### **1. G2N 웹훅 서버 시작 실패**
- **오류**: `UnicodeDecodeError: 'utf-8' codec can't decode byte 0xff in position 0: invalid start byte`
- **원인**: config.env 파일의 BOM(Byte Order Mark) 또는 바이너리 인코딩 문제
- **영향**: G2N 이벤트 발행 불가, /health 200 응답 미확보

### **2. Notion DB 속성 오류**
- **오류**: 400 Validation Error - 모든 속성명이 존재하지 않음
- **원인**: 실제 DB 스키마와 코드의 속성명 불일치
- **영향**: Notion 페이지 생성 불가, 단건/10건 확장 차단
