## 🎯 **서명 검증 문제 분석**

### **❌ 발견된 문제**
- **오류**: "Invalid signature" 지속적 발생
- **영향**: apply 모드 실행 불가
- **원인**: HMAC 서명 생성 및 검증 로직 불일치

### **🔍 원인 분석**

#### **1. JSON 직렬화 옵션 불일치**
- **클라이언트**: `json.dumps(data, sort_keys=True, ensure_ascii=False, separators=(',', ':'))`
- **서버**: `json.dumps(payload, sort_keys=True)` (기본 옵션)
- **결과**: 서로 다른 직렬화로 인한 서명 불일치

#### **2. 타임스탬프 만료 문제**
- **기존**: 5분 유효기간
- **문제**: 테스트 중 시간 경과로 만료
- **해결**: 10분으로 확장

#### **3. 서명 검증 로직**
- **현재**: `json.dumps(payload, sort_keys=True)` 사용
- **필요**: 클라이언트와 동일한 직렬화 옵션 적용
