## 📋 실행 개요

### 목표
KPI 48h·7d 자동 갱신과 링크 검증을 24x7로 상시화하여 "운영 고정" 상태로 전환

### 주요 성과
- **스케줄러 구축**: APScheduler + Redis 기반 24x7 운영
- **KPI 자동 갱신**: 48h·7d 동시 표출 및 트렌드 분석
- **링크 검증**: 5분 간격 검증 및 단계별 경보 시스템
- **운영 가드**: 경보 억제, 로그 압축, 민감정보 마스킹

## 🚀 핵심 성과

### 1. 링크 검증 스케줄러 구축
- **주기**: 5분 간격 실행
- **재시도**: 5s → 15s → 45s 지수 백오프
- **판정 기준**: HTTP 200, ≤1.5s, HTTPS, Notion URL, 3xx 최대 1회
- **경보 단계**: L1(2회) → L2(3회) → L3(5회)
- **경보 억제**: 동일 원인 15분 중복 억제
- **구현**: APScheduler + Redis JobStore + 분산 락

### 2. 대문 KPI 카드 자동 갱신
- **주기**: 15분 캐시 갱신
- **데이터 구조**: 48h_kpi, 7d_kpi 각각 success_rate, p95_latency_ms
- **표시 요소**: 48h·7d 동시 카드 + 트렌드(증감 화살표)
- **실패 처리**: 3회 연속 실패 시 L2 주의
- **캐시**: Redis 우선, in-memory 폴백

### 3. 운영 가드·정책
- **장애 대응**: L2 발생 시 수동 갱신 절차, L3 시 운영자 호출
- **알림 채널**: Slack 기본, L3 위험 시 이메일 병행
- **동시성**: APScheduler + Redis 락으로 다중 인스턴스 충돌 방지
- **백업**: KPI 집계 스냅샷을 일별 json.gz로 7일 보관
- **마스킹**: 토큰·프로젝트 ID·내부 URL 민감 구간 마스킹 강화
