## 🔑 **노션 통합 토큰(Secret Key) 발급 가이드**

노션 통합 토큰은 **데이터베이스에 접근하고 수정할 수 있는 권한**을 부여하는 비밀 키이므로, 보안에 유의해 주셔야 합니다.

### 1단계: 노션 '통합(Integrations)' 페이지 접속

1.  웹 브라우저에서 Notion에 로그인합니다.
2.  좌측 사이드바 상단의 **'설정 및 멤버(Settings & Members)'**를 클릭합니다.
3.  좌측 메뉴에서 **'내 통합(My integrations)'**을 클릭합니다.

### 2단계: 새 통합(New Integration) 생성

1.  페이지 상단에서 **'+ 새 통합 만들기(+ New integration)'** 버튼을 클릭합니다.
2.  **'통합 이름(Name of integration)'** 필드에 다음과 같이 입력합니다:
    * **`ZOBIS_AUTOMATION_SYSTEM`** (프로젝트의 목적에 맞게 명확하게 지정)
3.  **'연결 대상 워크스페이스(Associated workspace)'**가 조대표님의 올바른 워크스페이스인지 확인합니다.
4.  **'콘텐츠 기능(Content Capabilities)'** 섹션에서 다음 권한을 체크합니다. (ZOBIS 시스템이 데이터베이스를 읽고, 속성을 수정하기 위한 최소 권한입니다.)
    * ✅ **콘텐츠 읽기(Read content)**
    * ✅ **콘텐츠 업데이트(Update content)**
    * (필요에 따라: 사용자 정보 읽기)

### 3단계: 통합 토큰(Secret Key) 발급

1.  모든 설정을 확인한 후, 하단의 **'제출(Submit)'** 버튼을 클릭하여 통합을 생성합니다.
2.  통합이 생성되면, **'비밀 토큰(Secret token)'**이라는 이름의 긴 문자열이 나타납니다.
3.  이 토큰 옆의 **'복사(Copy)'** 버튼을 눌러 문자열을 안전하게 복사합니다.

| 🚨 **주의** |
| :--- |
| 이 **비밀 토큰(`secret_xxxxxxxxxxxxxxx`)**은 노션 API 키(Secret Key)이며, 노션에서 다시 볼 수 없으니 **서대리 팀에게 안전하게 전달**해 주셔야 합니다. |

### 4단계: 타겟 데이터베이스 권한 부여 (필수)

토큰을 발급받았더라도, 해당 통합이 실제 **노션 DB(`📘 ZOBIS 개발문서 DB`)에 접근**할 수 있도록 권한을 부여해야 합니다.

1.  `📘 ZOBIS 개발문서 DB` 페이지를 엽니다.
2.  페이지 우측 상단의 **'공유(Share)'** 버튼을 클릭합니다.
3.  **'ZOBIS\_AUTOMATION\_SYSTEM'**을 검색하여 선택합니다.
4.  권한을 **'수정 가능(Can edit)'**으로 설정하고 **'초대(Invite)'**를 클릭합니다.

이제 **`ZOBIS_AUTOMATION_SYSTEM`** 통합이 `📘 ZOBIS 개발문서 DB`에 대한 모든 권한을 획득했습니다.

| **1. 리뷰 대기 (칸반 뷰)** | **가장 중요한 의사결정 지점** (매일 아침 1순위) | $\mathbf{\text{AI}}$ $\mathbf{\text{신뢰도}}$ $\mathbf{\le}$ $\mathbf{0.6}$인 문서만 모여 있습니다. **AI가 해결 못한 치명적인 기회/위험** 문서를 먼저 확인하여 최종 판단을 내립니다. |
| **2. 고우선 인사이트 (갤러리 뷰)** | **핵심 트렌드 파악 및 학습** (매일 아침 2순위) | **`중요도`**가 **'High'**이고 **`상태`**가 **'분류완료'**된 카드만 필터링합니다. **`목적 요약`**만 빠르게 읽어 오늘 업계의 핵심 흐름을 파악합니다. |
| **3. 도메인별 리소스 (테이블 뷰)** | **제안서 작성 및 심층 자료 검색** | **`핵심 기술`** 태그(예: '방위산업')를 기준으로 필터링하여, **필요한 전문 자료**를 신속하게 찾고 AI가 제시한 **`근거 인용`**을 통해 사실을 검증합니다. |

#### **B. Stage 3 기능의 사용(가동) 방식**

Stage 3는 조대표님이 **수동으로 조작할 필요가 없습니다.** Stage 2가 완료되는 순간 **자동으로 발동**합니다.

1.  **트리거 (Notion Automation):** Stage 2에서 Drive 파일이 Notion DB에 **`링크`**와 **`제목`**을 채우는 순간, **Notion Automation Rule**이 이벤트를 감지합니다.
2.  **AI 분석 (Cloud Run):** Automation Rule이 **ZOBIS 웹훅 Public URL**을 호출하면, **서대리의 Cloud Run 서버**가 LLM 분석을 수행하고 **자동으로 모든 속성(요약, 중요도 등)**을 채웁니다.
3.  **결과 확인 (조대표):** 조대표님은 **5분 후** 대시보드에 접속하여 **AI가 채워 넣은 최종 결과**를 확인하고 의사결정하시면 됩니다.

**요약:** 조대표님께서는 **'ZOBIS 시스템을 켜는'** 행위 없이, **완성된 결과물**을 **ZOBIS 대시보드**에서 확인하는 것만으로 **Stage 3의 모든 지능**을 활용하실 수 있습니다.
