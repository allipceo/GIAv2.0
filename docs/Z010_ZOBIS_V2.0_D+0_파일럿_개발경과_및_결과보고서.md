## 🚨 **2. 직면했던 주요 문제점**

### **2.1 Flask dotenv 인코딩 오류**
```
UnicodeDecodeError: 'utf-8' codec can't decode byte 0xff in position 0: invalid start byte
```
- **원인**: Flask가 자동으로 `.env` 파일을 로드할 때 인코딩 문제 발생
- **영향**: 웹훅 서버가 전혀 실행되지 않음
- **해결**: `app.run(load_dotenv=False)` 적용으로 자동 로딩 비활성화

### **2.2 모듈 import 경로 문제**
```
ModuleNotFoundError: No module named 'src'
```
- **원인**: Python 프로젝트 구조에서 상대 import 경로 설정 문제
- **영향**: ZOBIS 프로세서 모듈을 불러올 수 없음
- **해결**: `__init__.py` 파일 생성 및 패키지 구조 정비

### **2.3 웹훅 서버 실행 실패**
- **원인**: 위의 두 문제로 인한 연쇄적 실패
- **영향**: 파일럿 테스트 진행 불가
- **해결**: 대안적 접근 방법으로 직접 실행 방식 채택
