- **리전**: asia-northeast3 (서울)
- **스케일링**: 자동 스케일링 (1-10 인스턴스)

## 🏗️ **1. 클라우드 배포 아키텍처**

### **Google Cloud Run 구성**
```
┌─────────────────────────────────────────────────────────────┐
│                    ZOBIS V2.0 Cloud Run                      │
├─────────────────────────────────────────────────────────────┤
│  Service: zobis-webhook-server                              │
│  Region: asia-northeast3                                    │
│  Memory: 2Gi                                                │
│  CPU: 2                                                     │
│  Max Instances: 10                                          │
│  Min Instances: 1                                           │
│  Timeout: 300s                                              │
│  Concurrency: 100                                           │
└─────────────────────────────────────────────────────────────┘
```

### **배포 파이프라인**
1. **Docker 이미지 빌드**: `Dockerfile` 기반
2. **Container Registry 푸시**: `gcr.io/zobis-v2-production/zobis-webhook-server`
3. **Cloud Run 배포**: 무중단 배포 (2 리비전 롤백)
4. **헬스체크**: `/health` 엔드포인트 제공
5. **모니터링 연동**: Cloud Monitoring 자동 설정

## 🔒 **3. 보안 및 인증 시스템**

### **인증 방식**
- **Bearer Token**: 서버 측 토큰 검증
- **HMAC 서명**: 요청 무결성 검증
- **타임스탬프**: 리플레이 공격 방지
- **IP 제한**: 허용 목록 기반 접근 제어

### **보안 헤더**
```
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
X-XSS-Protection: 1; mode=block
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'
```

### **시크릿 관리**
- **Google Secret Manager**: API 키 및 토큰 저장
- **환경 변수**: 런타임 시 주입
- **토큰 순환**: 30일 주기 갱신
- **접근 로그**: 모든 인증 시도 기록

## ⚡ **4. 성능 최적화 및 확장**

### **30건 확장 테스트**
- **동시성**: 5개 병렬 처리
- **목표 성공률**: ≥95%
- **목표 처리 시간**: P95 ≤20초
- **처리량**: ≥30 문서/분

### **100건 배치 설계**
- **배치 크기**: 10건씩 처리
- **큐 시스템**: Redis 기반 작업 큐
- **재시도 정책**: 3회 + 지수 백오프
- **장애 복구**: 자동 롤백 메커니즘

### **성능 튜닝**
- **메모리 최적화**: 2Gi → 4Gi (필요시)
- **CPU 최적화**: 2 → 4 코어 (필요시)
- **동시성 조정**: 100 → 200 (필요시)
- **타임아웃 조정**: 300초 → 600초 (필요시)
