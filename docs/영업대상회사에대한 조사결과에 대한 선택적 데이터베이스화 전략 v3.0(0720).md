## 🔧 스마트 필터링 프로세스

### **Step 1: 자동 스캔 및 우선순위 판정**

```python
def smart_content_scanner(document):
    """문서 내용을 스캔하여 DB화 우선순위 판정"""
    
    priority_score = 0
    
    # 키워드 기반 점수 계산
    for keyword in 핵심_키워드:
        if keyword in document:
            priority_score += 10
    
    for keyword in 분석_키워드:
        if keyword in document:
            priority_score += 5
    
    # 수치 데이터 포함 여부
    if contains_numbers(document):
        priority_score += 5
    
    # 보험 관련성 평가
    if insurance_related(document):
        priority_score += 15
    
    return priority_score
```

### **Step 2: 선별적 추출 기준**

| 우선순위 점수 | 처리 방식 | DB화 비율 |
|---------------|-----------|-----------|
| **30점 이상** | 완전 구조화 | 90-100% |
| **20-29점** | 선별 구조화 | 50-70% |
| **10-19점** | 핵심만 추출 | 20-30% |
| **10점 미만** | 원문 보관만 | 0-10% |

### **Step 3: 6개 DB 매핑 판정**

```python
def db_mapping_decision(content, priority_score):
    """내용과 우선순위에 따른 DB 매핑 결정"""
    
    if priority_score >= 20:
        # 높은 우선순위: 정확한 DB 분류
        return classify_to_specific_db(content)
    
    elif priority_score >= 10:
        # 중간 우선순위: 핵심 정보만 추출
        return extract_key_info_only(content)
    
    else:
        # 낮은 우선순위: 원문 링크만 저장
        return store_reference_only(content)
```
