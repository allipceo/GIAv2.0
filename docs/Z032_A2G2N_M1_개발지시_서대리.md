## 📋 **필요한 시크릿 목록 및 환경변수**

### **Google Drive API**
```bash
GOOGLE_DRIVE_CREDENTIALS_JSON=# 서비스 계정 JSON 키 (Base64 인코딩)
GOOGLE_DRIVE_FOLDER_ID=# INBOX/AI2G 폴더 ID
```

### **Notion API**
```bash
NOTION_API_KEY=# 최신 Notion API 키
NOTION_DATABASE_ID_PROJECT_RESOURCES=# 프로젝트리소스 DB ID
NOTION_DATABASE_ID_DEVELOPMENT_DOCS=# 개발문서 DB ID
```

### **AI 서비스**
```bash
OPENAI_API_KEY=# OpenAI API 키 (웹 리서치용)
GOOGLE_SEARCH_API_KEY=# Google Search API 키
GOOGLE_SEARCH_ENGINE_ID=# Custom Search Engine ID
```

### **웹 리서치 서비스**
```bash
SERPAPI_KEY=# SerpAPI 키 (백업 검색 엔진)
NEWSAPI_KEY=# NewsAPI 키 (뉴스 수집용)
```

### **모니터링 및 로깅**
```bash
LOG_LEVEL=INFO
TRACE_ENABLED=true
MONITORING_WEBHOOK_URL=# 알림 웹훅 URL
```

### **보안 설정**
```bash
ENCRYPTION_KEY=# 파일 암호화용 키
RATE_LIMIT_PER_MINUTE=60
MAX_RETRY_ATTEMPTS=3
```

## 🔧 **명령 채널 및 버튼**

### **Notion 명령 버튼**
- **버튼명**: A2G2N
- **즉시 활성화**: 차단 이슈 발생 시 즉시 우회 또는 임시 조치 후 계속 진행

### **기본 동작 파라미터**
```json
{
  "topic": "서남해해상풍력발전사업",
  "keywords": ["해상풍력발전","풍력발전","신재생에너지","발전사업","에너지사업"],
  "project_id": "SOUTH_WEST_OFFSHORE_WIND",
  "depth": 2,
  "max_items": 5,
  "lang": "ko",
  "trace_id": "<uuid>",
  "callback_url": "<Stage2_webhook>"
}
```

### **엔드포인트 설계**
```
POST https://a2g2n-command-[region]-[project-id].cloudfunctions.net/process-command
```

### **인증 방식**
- **Notion API Key 기반 인증**
- **Request Header**: `Authorization: Bearer [NOTION_API_KEY]`
- **추가 검증**: Notion 사용자 ID 확인

## 🔧 **수집 산출 규격 (AI2G)**

### **산출 파일**
- **형식**: PDF 또는 MD + meta.json(동명)
- **meta.json 필수 필드**: title, url, source_domain, published_at, collected_at, content_hash, topics, project_hint
- **저장 경로**: `/INBOX/AI2G/서남해해상풍력발전사업/날짜_제목_해시.pdf`
- **준수사항**: 로봇·저작권·약관. 전문 저장 불가 시 링크+요약

## 🔗 **G2N 연동**

### **이벤트 발행**
- **payload**: drive_path, file_id, file_url, meta_json_url, project_hint, content_hash
- **라우팅**: INBOX 3폴더 규칙 준수
- **실패 시 재시도**: 3회(5s/15s/45s 백오프)

## 📝 **Notion 등록 (최초 속성)**

### **대상 DB**
- **우선**: 프로젝트리소스 DB
- **대체**: 개발문서 DB (프로젝트리소스 DB 없을 시)

### **기본 속성 세팅**
- **문서 제목**: A2G_원제목
- **링크**: 원문 URL
- **Google Drive URL**: 파일 URL
- **수집 경로**: AI2G
- **리소스 타입**: 규칙 기반(뉴스·법규·리서치·기업자료·기타)
- **작성일**: collected_at
- **상태**: 초안
- **중복 방지**: content_hash로 idempotency

## 📊 **품질·모니터링**

### **필수 로그**
- **필드**: trace_id, step, duration_ms, status, err_code, err_msg
- **핵심 지표**: 수집 성공률, 라우팅 정확도, 평균 처리 시간, 재시도율
- **장애 기준**: 5xx 3회 연속 또는 성공률 < 90% 즉시 보고

## 🔒 **보안·시크릿**

### **키 관리**
- **모든 키**: 환경변수·비밀저장소로 주입. 저장소 커밋 금지
- **Notion API 키**: 최신값 적용 후 동작 점검
- **Drive 서비스계정 키**: 평문 저장 금지
