## 🎯 **프로세스 개요**

### **시스템 목표**
Google Drive "ZOBIS/INBOX" 폴더에 업로드된 문서를 자동으로 Notion "📘 ZOBIS 개발문서 DB"에 동기화하고, AI가 자동으로 분석하여 분류, 요약, 태그를 지정하는 완전 자동화 시스템

### **핵심 기능**
- **1단계**: Google Drive → Notion DB 자동 동기화 (파일명, 링크, 기본 속성)
- **2단계**: AI 자동 분석 (분류, 요약, 태그, 인사이트)
- **완전 자동화**: 버튼 클릭 한 번으로 모든 작업 완료
- **중복 방지**: 기존 파일은 건너뛰고 신규 파일만 처리

## 🎯 **핵심 기능 상세**

### **🔄 1단계: Google Drive → Notion DB**

#### **기능**
- Google Drive API를 통한 폴더 스캔
- 파일 메타데이터 수집 (파일명, URL, 수정일, MIME 타입, 크기)
- 중복 검사 (Google Drive URL 기준)
- Notion DB에 기본 정보 저장

#### **처리 로직**
```python
def sync_drive_to_notion():
    # 1. Google Drive 폴더 스캔
    files = get_drive_files(folder_id)
    
    # 2. 중복 검사
    for file in files:
        if not check_notion_duplicate(file['webViewLink']):
            # 3. Notion DB에 저장
            create_notion_page(file)
```

### **🤖 2단계: AI 자동 분석**

#### **기능**
- LLM을 통한 문서 내용 분석
- 문서 유형 자동 분류
- 중요도 평가
- 태그 자동 지정
- 핵심 내용 요약

#### **AI 분석 프로세스**
```python
def analyze_document(content):
    # 1. LLM API 호출
    result = call_llm_api(content)
    
    # 2. 결과 검증
    validated_result = validate_result(result)
    
    # 3. Notion DB 업데이트
    update_notion_page(validated_result)
```
