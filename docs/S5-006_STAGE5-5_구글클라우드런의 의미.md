1. 💡 Cloud Run (GCR) 핵심 개념 해설
서대리 팀이 개발한 ZOBIS 서버가 운영될 Google Cloud Run은 서버리스(Serverless) 기술을 대표하는 플랫폼입니다. 이는 비용 효율과 운영 안정성 측면에서 ZOBIS에 최적화된 선택입니다.

📌 선과장님께: GCR과 Notion 연동의 의미
Cloud Run은 웹훅이 전송될 때만 깨어납니다. 선과장님이 Notion에서 [C2N] 버튼을 클릭하면, 이 웹훅이 GCR 서버를 깨우고(콜드 스타트), 작업을 처리한 후 다시 잠재우게 됩니다.
