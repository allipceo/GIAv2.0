### **🔍 문제 분석**

**1. Flask 자동 .env 로드 문제 (근본 원인)**
- **문제**: Flask가 `app.run()` 호출 시 자동으로 `cli.load_dotenv()` 실행
- **영향**: `.env` 파일의 BOM 문제로 인해 서버 시작 불가
- **오류**: `UnicodeDecodeError: 'utf-8' codec can't decode byte 0xff in position 0: invalid start byte`

**2. 시도한 해결 방법들 (모두 실패)**
- **방법 1**: Flask 설정에서 자동 .env 로드 비활성화 (`app.config['LOAD_DOTENV'] = False`)
  - **결과**: ❌ 실패 (Flask가 여전히 자동으로 .env 파일을 로드)
- **방법 2**: 환경변수 직접 설정 (하드코딩)
  - **결과**: ❌ 실패 (Flask가 여전히 자동으로 .env 파일을 로드)
- **방법 3**: .env 파일 완전 제거
  - **결과**: ❌ 실패 (Flask가 여전히 자동으로 .env 파일을 로드)

**3. 현재 상황**
- **서버 시작**: ❌ 불가능
- **/health 엔드포인트**: ❌ 접근 불가
- **포트 8000**: ❌ 바인딩 실패
- **Flask 자동 .env 로드**: ❌ 여전히 실행됨
