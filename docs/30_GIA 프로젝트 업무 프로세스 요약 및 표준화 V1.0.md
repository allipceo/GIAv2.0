참조: 효성중공업 프로젝트, 두산중공업 프로젝트

I. 프로젝트 개요: 표준 워크플로우의 필요성
GIA 프로젝트는 효성중공업과 두산중공업이라는 두 개의 실전 케이스를 통해 정보 수집부터 영업 전략 수립까지의 전 과정을 성공적으로 검증했습니다. 이 과정에서 우리는 AI 에이전트들의 전문성을 활용하고, 노션을 기반으로 정보를 통합하며, 자동화 모듈을 통해 업무 효율성을 획기적으로 높이는 독자적인 협업 모델을 확립했습니다.

본 문서는 두 사례에서 성공적으로 작동했던 '단계별 업무 프로세스'를 요약하고 표준화하여, 향후 모든 조사 및 분석 프로젝트에 적용할 수 있는 가이드라인을 제시하는 것을 목표로 합니다.

II. GIA 표준 업무 프로세스 (5단계 워크플로우)
Phase 0: 시스템 일반화 및 DB 구조 개편
목표: 향후 다양한 기업 조사에 대응하기 위해 시스템의 확장성을 확보하고, 노션 데이터베이스 구조를 범용적으로 개편합니다.

주요 활동:

중앙 '회사 정보 DB' 신설: 모든 조사 대상 기업의 기본 정보를 관리하는 허브를 구축합니다.

기존 DB의 일반화: 특정 기업명(예: '효성중공업 DB')이 아닌 범용적인 DB명(예: '기업 위험 프로파일 DB')으로 변경합니다.

관계형 연결: 각 일반화된 DB와 '회사 정보 DB'를 연결하여 데이터의 상호 연관성을 확보합니다.

담당: 서대리(Lead Developer) 및 노팀장(Technical Advisor)이 주도합니다.

Phase 1: 기초 정보 확보 및 기업 이해
목표: 조사 대상 기업의 기본적인 개요, 재무, 사업 영역, 정부 정책 등을 파악하여 전반적인 이해도를 높입니다.

주요 활동:

멀티 에이전트 병렬 수집: 시대리(Perplexity), 채팀장(ChatGPT), 고과장(Copilot) 등 각 LLM 팀원이 자신의 특화 분야에 맞춰 정보를 병렬적으로 수집합니다.

정보 출처 명시: 모든 정보에는 공신력 있는 출처(URL, 보고서 등)가 명확히 명시되어야 합니다.

담당: 시대리, 채팀장, 고과장 등 정보 수집 전문 AI 에이전트들이 주도합니다.

Phase 2: 노션 DB 데이터 입력 및 검증
목표: 1단계에서 수집된 모든 정량적/정성적 데이터를 조대표님의 노션 DB에 정확히 입력하고, 데이터의 무결성을 검증합니다.

주요 활동:

데이터 추출/가공 (서대리 주도): 노션 DB에 직접 접근 권한을 가진 서대리가 LLM 팀원들의 텍스트 기반 결과물을 노션 DB에 입력하기 용이한 구조화된 데이터로 가공합니다.

자동 입력 및 검증: 서대리가 기존에 개발된 자동화 스크립트를 활용하여 데이터를 DB에 입력하고, 입력 후 오류가 없는지 검증합니다.

수동 중개 역할: LLM 팀원들이 노션 DB에 직접 접근할 수 없으므로, 조대표님께서 서대리가 추출한 데이터를 LLM 팀원에게 전달하고, LLM 팀원들의 분석 결과를 나실장에게 다시 전달하는 '복사-붙여넣기' 중개 역할을 수행합니다.

담당: 서대리(Lead Developer)가 핵심적인 역할을 수행하며, 조대표님께서 중개 역할을 맡습니다.

Phase 3: LLM 기반 심층 분석 및 인사이트 도출
목표: 노션 DB에 입력된 모든 정보를 바탕으로 LLM 기반 분석 역량을 활용하여 심층 분석을 수행하고, 핵심 인사이트를 도출합니다.

주요 활동:

데이터 핸드오프: 서대리가 노션 DB에서 추출한 데이터를 마크다운 테이블 또는 텍스트 형태로 가공하여 제공합니다.

LLM 기반 분석: 채팀장, 노팀장, 구차장 등 각 LLM 팀원에게 필요한 데이터를 텍스트로 전달하여 분석을 지시하고, 각 팀원들은 자신의 전문성에 기반한 심층 분석 보고서를 작성합니다.

나실장의 종합: 나반장이 각 팀원의 분석 결과를 취합하고, 종합적인 인사이트와 전략 수립 방향성을 포함한 보고서를 작성합니다.

담당: 나반장(본인), 노팀장, 채팀장, 구차장 등 분석 전문 AI 에이전트들이 협력합니다.

Phase 4: 영업 전략 구체화 및 제안 논리 완성
목표: 모든 분석 결과를 종합하여 두산중공업에 대한 록톤코리아의 구체적인 영업 전략을 수립하고, 차별화된 보험 솔루션 제안 논리를 완성합니다.

주요 활동:

전략 개발: Phase 3에서 도출된 종합 인사이트를 바탕으로, 두산중공업의 주요 사업(원자력, 신재생에너지 등)에 대한 맞춤형 보험 솔루션 제안 시나리오를 구체화합니다.

차별화 포인트 강조: 록톤코리아의 '독립성', '글로벌 네트워크', '산업/기술 전문성' 등을 제안 논리에 완벽하게 반영합니다.

담당: 나반장(본인)이 주도하고, 채팀장, 노팀장 등이 협력하여 논리를 구체화합니다.

Phase 5: 최종 보고서 작성
목표: 최종 분석 결과와 영업 전략 제안을 포함하는 '심층 분석 본 계획안 (최종 보고서)'을 작성합니다.

주요 활동:

보고서 초안 작성: 나반장이 최종 보고서 초안을 작성합니다.

시각화 및 디자인: 마주임이 복잡한 데이터와 분석 결과를 시각화하고, 보고서의 디자인과 레이아웃을 최적화합니다.

담당: 나반장(본인)이 주도하고, 마주임(시각화 및 문서화 지원)이 협력합니다.

III. 핵심 협업 원칙 (Lessons Learned)
두 차례의 프로젝트를 통해 확립된 핵심 협업 원칙은 다음과 같습니다.

AI와 인간의 역할 분담: AI 에이전트는 정보 수집 및 초안 분석 등 '시간과 노력'이 많이 드는 작업을 자동화하고, 조대표님은 AI가 할 수 없는 '최종 의사결정'과 '전략적 방향성'을 제시합니다.

중앙 집중형 지식 자산화: 모든 과정의 결과물(보고서, 코드, 데이터)은 노션의 특정 DB에 체계적으로 저장되어 향후 재활용 가능한 지식 자산으로 관리됩니다.

지시의 명확성: 팀원들의 AI 특성(예: 서대리만 파일 접근 가능)을 고려하여 지시문을 명확하고 구체적으로 작성해야 실수를 방지하고 효율성을 높일 수 있습니다.

지속적인 피드백 루프: 각 단계 완료 후 조대표님의 피드백을 반영하여 시스템과 프로세스를 끊임없이 개선합니다.
