1) G2 파일럿 10건 실행

- 실행 정책
    - 동시성 3~5
    - 재시도 1회
    - 잔여 실패는 “AI 처리 실패(재검토)” 라벨 처리
- 가드·보안
    - 정규화 서명(HMAC+nonce+ts, canonical JSON, NFC, base64url)
    - schema_hash: dryrun=WARNING, apply=HARD FAIL
    - 옵션 화이트리스트는 실제 DB 옵션 동기화 유지
- 절차
    1. 후보 10건 확정 → dryrun 일괄 실행
    2. dryrun OK 확인 후 apply 일괄 실행
    3. 실패 발생 시 원인 분류(권한/옵션/네트워크/스키마/기타)와 재시도 결과 기록
- 산출물
    - g2_pilot_run_<ts>.md: 건별 결과, 성공률, 원인 분류표
    - 개별 실행 로그: logs/<case>*<id>*<ts>.md 10건
    - Z073 증빙 첨부 및 상단 요약 갱신[[2]](https://www.notion.so/Z073_-1-2-3-1935f44dcfc44e8bae11cca4c9acdf66?pvs=21)
- 합격 기준(AC)
    - 10/10 성공 또는 재시도 후 미해결 0건
    - 가드 체인 전 구간 통과(서명·스키마·옵션)
