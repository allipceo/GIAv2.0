## 🚨 **핵심 문제점 및 해결 상황**

### **1. Flask 자동 .env 로드 문제 (해결 완료)**
- **문제**: Flask가 `app.run()` 호출 시 자동으로 `cli.load_dotenv()` 실행
- **영향**: `.env` 파일의 BOM 문제로 인해 서버 시작 불가
- **해결 방법**: 
  - Flask 설정에서 자동 .env 로드 비활성화 (`app.config['LOAD_DOTENV'] = False`)
  - 환경변수 직접 설정 (하드코딩)
  - `.env` 파일 완전 제거
- **결과**: ✅ **해결 완료** (Flask 자동 .env 로드 문제 원천 차단)

### **2. Notion DB 속성 불일치 문제 (해결 진행 중)**
- **문제**: JSON Payload의 속성 키가 Notion DB의 실제 한글 속성명과 100% 불일치
- **해결 방법**: 
  - 선과장님 지시사항에 따른 최소 세트 속성명 적용 완료
  - 실제 Notion DB 화면에서 속성명 1:1 비교 필요
  - 최소 세트 속성명으로 단일 테스트 후 점진적 확장
- **결과**: 🔄 **해결 진행 중** (실제 DB 스키마 확인 필요)
