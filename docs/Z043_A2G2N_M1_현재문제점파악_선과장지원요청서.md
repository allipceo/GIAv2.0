## 📋 **현재 문제점 종합 분석**

### **1. G2N 웹훅 서버 미가동 문제**
**문제 현황:**
- **상태**: 서버 시작 시도했으나 백그라운드 실행 실패
- **오류**: `UnicodeDecodeError: 'utf-8' codec can't decode byte 0xff in position 0: invalid start byte`
- **영향**: G2N 이벤트 발행 불가, /health 200 응답 미확보
- **시도한 해결책**: 
  - .env 파일 UTF-8 인코딩 명시
  - 0.0.0.0:8000 바인딩 설정
  - 백그라운드 실행 시도

**차단 원인:**
- config.env 파일의 BOM(Byte Order Mark) 또는 바이너리 인코딩 문제
- Flask의 dotenv 로딩 시 UTF-8 디코딩 실패

### **2. Notion DB 속성 오류 문제**
**문제 현황:**
- **상태**: 400 Validation Error 지속 발생
- **오류**: `"문서 제목 is not a property that exists. 링크 is not a property that exists. Google Drive URL is not a property that exists. 수집 경로 is not a property that exists. 작성일 is not a property that exists. 상태 is not a property that exists. 리소스 타입 is not a property that exists."`
- **영향**: Notion 페이지 생성 불가, 단건/10건 확장 차단

**차단 원인:**
- Notion DB 스키마의 실제 속성명과 코드의 속성명 불일치
- 프로젝트리소스 DB 또는 ZOBIS 개발문서 DB의 속성명 확인 필요

### **3. 외부 URL 확보 문제**
**문제 현황:**
- **상태**: 터널 설정 미완료
- **영향**: 외부 서비스에서 G2N 웹훅 접근 불가
- **필요사항**: ngrok 또는 cloudflared 터널 설정

### **3. 우회 조치 적용**

# 재시도 로직 3회 (5s→15s→45s 지수 백오프)
