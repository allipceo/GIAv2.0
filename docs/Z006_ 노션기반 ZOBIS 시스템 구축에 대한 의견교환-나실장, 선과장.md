ZOBIS DB 표준 스키마 및 관계형 ID 제공.

4. 향후 협의 및 ZOBIS 고도화 방향 (V2.0 논의 요청)

4.1. 노션 AI 활용을 통한 인사이트 도출 고도화
현재 '제목 + 링크' 전략을 채택했습니다. 노션 AI가 이 링크된 문서 내용을 분석하여 '목적 요약' 필드를 자동으로 채우고, 정보 간의 연관성을 파악하는 고급 기능을 구현하고자 합니다.

협의 요청 1: Notion AI의 '자동 요약' 및 '자동 분류' 기능을 ZOBIS DB의 표준 속성(문서 성격, 핵심기술)과 연동하여 Notion Automation으로 구현할 수 있는 최적의 방법론을 제시해 주십시오.

4.2. 조대표님 전용 '대시보드' 및 '뷰' 최적화
ZOBIS는 조대표님의 의사결정 속도 단축을 목표로 합니다.

협의 요청 2: 수집된 정보가 '프로젝트/모듈' 관계를 통해 연결될 때, 조대표님께서 매일 아침 10분 만에 핵심 정보만 파악할 수 있도록 '조대표 전용 지능형 대시보드 뷰' 설계 방안을 제안해 주십시오. (예: 위험/기회 자동 알림 보드, 주력 분야별 트렌드 차트 등)

4.3. ZOBIS V2.0 로드맵 확정
다음 단계 목표인 **'지능형 분석'**을 위해, LLM 기반 예측 모델링 및 복합 이벤트 감지 기능 구현에 대한 선과장님의 기술적/플랫폼적 관점을 제시해 주시면 감사하겠습니다.

## 🚀 ZOBIS V2.0: Notion AI Automation 실행 계획 확정

선과장님께서 공유해 주신 노션 페이지를 통해 **AI Prompt 설계**와 **Automation Rule**에 대한 구체적인 방안을 파악했습니다.

### 1. Notion AI Automation Prompt 확정

선과장님께서 조대표님의 주력 분야(방위산업, 신재생에너지, 보험중개)를 정확히 반영하여 프롬프트 설계의 방향을 제시해 주셨습니다. 서대리가 구현할 **LLM API 연동 모듈**과 Notion AI가 함께 사용할 **최종 Prompt의 구성 요소**를 확정합니다.

| DB 속성 | 자동 채움 목표 | 확정 Prompt 설계 방향 |
| :--- | :--- | :--- |
| **목적 요약** | 비즈니스 관점 핵심 요약 (1~2문장) | **'조대표님의 업무 맥락(방위산업, 신재생에너지, 보험중개)에서 이 정보가 갖는 비즈니스 기회 또는 위험을 1~2문장으로 요약하십시오.'** |
| **문서 성격** | [개발경과] \| [교훈] \| [매뉴얼] 중 택 1 | **'이 문서를 개발경과, 교훈, 매뉴얼 중 하나로 분류하고 그 이유를 한 문장으로 설명하십시오.'** |
| **핵심 기술** | [신재생에너지] \| [방위산업] \| [보험중개] \| [IT/자동화] 중 택 1~2 | **'이 문서의 주요 도메인을 신재생에너지, 방위산업, 보험중개, IT/자동화 중에서 1~2개 선택하여 제시하십시오.'** |
| **중요도** | [High] \| [Medium] \| [Low] 중 택 1 | **'이 정보가 조대표님의 의사결정 시급성 및 영향력 기준으로 High, Medium, Low 중 어디에 속하는지 판단하십시오.'** |

### 2. Notion Automation Rule 및 오류 처리 확정

Notion Automation Rule은 **효율성**과 **안정성**을 최우선으로 설정하겠습니다.

| 요청 항목 | 선과장님 제안 검토 및 확정 Rule | 서대리/선과장 역할 |
| :--- | :--- | :--- |
| **Automation 실행 조건** | **새 페이지 생성 시** (동기화 직후) | **확정:** 새 페이지 생성 시 Automation Rule이 **즉시 발동**하도록 설정합니다. (서대리가 동기화 과정에서 AI 지연을 고려한 배치/딜레이 처리를 이미 구현했기 때문에 즉시 실행이 가능합니다.) |
| **AI 오류 처리** | **'상태'** 속성 전환 | **확정:** Notion AI 또는 LLM API 처리 중 오류 발생 시, 해당 페이지의 **'상태'** 속성을 **'AI 처리 실패 (재검토)'**로 자동 변경하고, 실패 로그를 기록하도록 서대리가 스크립트에 예외 처리 로직을 추가합니다. |
| **성능 최적화** | **AI 연산 부하 분산** | **선과장:** Notion AI의 네이티브 기능을 활용하여 1차 분류 및 요약을 수행. **서대리:** Notion AI가 처리하기 어려운 **복합 이벤트 감지 및 예측 모델링**은 **외부 LLM API**(`insight_generator.py`)로 분기하여 처리합니다. |
