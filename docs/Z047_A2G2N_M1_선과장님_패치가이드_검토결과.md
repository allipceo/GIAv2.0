## 🎯 **1. G2N 웹훅 서버 시작 실패 해결**

### **원인 분석 (정확함)**
- `.env` 파일이 UTF-8 BOM 또는 바이너리로 저장되어 파서가 0xFF 등 비정상 바이트를 만나 크래시
- 현재 `UnicodeDecodeError: 'utf-8' codec can't decode byte 0xff in position 0` 오류 발생

### **패치 스니펫 (적용 가능)**
```python
# src/g2n_webhook_server.py 수정
import os
from flask import Flask, jsonify
try:
    from dotenv import load_dotenv
    load_dotenv(encoding="utf-8")  # BOM 이슈 회피
except Exception:
    pass  # .env 미사용/로컬 환경이면 무시

app = Flask(__name__)

@app.route("/health", methods=['GET'])
def health():
    return jsonify({"status":"ok","version":"v1","uptime":1}), 200

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=int(os.getenv("PORT", 8000)))
```

### **실행 체크리스트 (즉시 실행 가능)**
- ✅ VS Code에서 .env를 "UTF-8(BOM 없음)"으로 다시 저장
- ✅ `python src/g2n_webhook_server.py` 실행 후 `curl http://127.0.0.1:8000/health` → 200 확인
- ✅ 서비스형 실행 시 gunicorn 권장: `gunicorn -w 2 -b 0.0.0.0:8000 app:app`

### **터널(외부 URL) 개통 (즉시 실행 가능)**
- **cloudflared**: `cloudflared tunnel --url http://localhost:8000`
- **ngrok**: `ngrok http 8000`
- 발급된 https URL로 `/health` 200 확인

## 🎯 **2. Notion 400 Validation Error 해결**

### **원인 분석 (정확함)**
- properties 키가 실제 스키마(한글 속성명)와 1:1로 일치하지 않거나 값 타입이 불일치
- 현재 `400 - {"object":"error","status":400,"code":"validation_error","message":"[property name] is not a property that exists."}` 오류 발생

### **최소 정상 세트 (정확함)**
- "문서 제목" title
- "링크" url  
- "Google Drive URL" url
- "수집 경로" select 값 "AI2G"
- "작성일" date.start(ISO-8601)
- "상태" status 값 "초안"

### **패치 스니펫 (적용 가능)**
```python
# src/a2g2n_final_fixed_executor.py 수정
payload = {
  "parent": { "database_id": TARGET_DB_ID },
  "properties": {
    "문서 제목": { "title": [{ "text": { "content": f"A2G_{title}" } }] },
    "링크": { "url": source_url },
    "Google Drive URL": { "url": drive_file_url },
    "수집 경로": { "select": { "name": "AI2G" } },
    "작성일": { "date": { "start": iso_date } },  # e.g., "2025-09-28"
    "상태": { "status": { "name": "초안" } }
  }
}
```

### **디버깅 팁 (유용함)**
- 400 발생 시 "실제 전송한 properties 키/값"을 로그에 남겨 현재 DB 스키마(한글 이름·옵션 철자)와 대조
- select/status 옵션 철자 1글자라도 다르면 400
- 날짜 형식은 반드시 ISO-8601
